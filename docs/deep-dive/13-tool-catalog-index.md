## Effects legend

MT=mutatesTarget, MS=mutatesSession (additive Evidence/session state), FS=writesFilesystem, LP=launchesProcess, NET=accessesNetwork, UI=changesUiState, DISC=mayDiscardData, EXEC=executesForeignCode (runs/drives code REA does not own: the target, a caller-chosen executable, or the app under test), DEV=mutatesDevice (changes an attached Android device). Flags are *possible* effects across the tool's supported inputs (`ToolEffects` doc comment, `src/contracts/toolEffects.ts`).
